## ContentDedup v0.2.0

First public release with a local web console.

### Highlights

- **Local web UI** — folder picker, type filters, live progress, cancel, thumbnails,
  per-group keeper selection, and confirmation before moving files.
- **Safe cleanup** — duplicates move to `.dedup-trash` with `manifest.json` and
  `journal.jsonl`; every move re-checks size, mtime, and SHA-256.
- **Multi-modal detection** — exact SHA-256 plus image pHash/dHash, video frame
  pHash sequences, Chromaprint audio fingerprints, document/text SimHash, and
  archive manifest hashes.
- **NAS-friendly** — SQLite incremental cache, staged scans, worker limits, and
  Docker deployment with ffmpeg + Chromaprint included.
- **One-command demo** — `python examples/create_demo.py ./demo`.

### Install

Docker:

```bash
MEDIA_DIR=/volume1/media docker compose up -d
```

Python:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e .
./start-web.sh
```

### Notes

- The web UI is currently in Simplified Chinese.
- The web console has no authentication; bind to localhost or a trusted LAN/VPN.
- Semantic embedding layer is reserved but not enabled.
- One-click trash restore is not implemented yet.
